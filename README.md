# Your Business Website

A fast, mobile-friendly, single-page business website. Plain HTML/CSS/JS — no build
step, no framework, no monthly software fees. It can be hosted **for free**.

## Files

| File | What it is |
|------|------------|
| `index.html` | All the page content (text, sections) |
| `styles.css` | The look — colours, fonts, spacing |
| `script.js` | Small bits of interactivity (mobile menu, year) |

## What YOU need to do (the only things I can't do for you)

### 1. Buy a domain name (~$10–15/year) — the only guaranteed cost
A domain is your web address, e.g. `yourbusiness.com`.

- **Where to buy:** [Cloudflare Registrar](https://www.cloudflare.com/products/registrar/) (cheapest, at-cost),
  [Namecheap](https://www.namecheap.com), or [Porkbun](https://porkbun.com).
- Search for the name you want, add to cart, pay. That's it — it's yours for a year.
- ⚠️ Buy the domain **only**. Skip the upsells (hosting, email, "site builder", privacy add-ons
  — privacy is usually free). You do **not** need their hosting; we host free elsewhere.

### 2. Set up a free contact-form service (5 minutes, free)
So the "Send message" form actually emails you.

1. Go to [Formspree.io](https://formspree.io) → sign up free.
2. Create a new form → it gives you a URL like `https://formspree.io/f/abcd1234`.
3. Tell me that URL (or paste it into `index.html` where it says `your-form-id`).

*(Optional — the site also shows a direct email link as a fallback, so this isn't blocking.)*

### 3. Send me your real details
So I can replace the placeholder content:
- Business name + tagline
- What you do (a sentence or two per service)
- Real email, phone, address
- Any logo/photos you have (optional — the site looks good without them)

## Hosting — I'll do this for you, for free

The site will be deployed to one of these free hosts (all $0, all fast, all with free HTTPS):

- **Cloudflare Pages** (recommended if you buy the domain at Cloudflare)
- **Netlify**
- **GitHub Pages**

Once it's live I'll give you a temporary free address (e.g. `your-site.pages.dev`) so you can
see it immediately. When your domain is ready, I'll give you the exact DNS records to point it
at the site — usually just copy-pasting 2 lines into your registrar dashboard.
